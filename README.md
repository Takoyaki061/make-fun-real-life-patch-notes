One line, at most 160 characters: a software patch note for a bug in real life / human biology, in the terse register of a real release note. The program writes exactly one line to `/output/entry.txt`:

> v2.4.1: fixed a bug where bladder urgency spikes to 100% the moment keys touch the front door lock. Workaround: clench and sprint.

The bladder's urgency meter jumping to maximum at the exact instant the front door is reached is a betrayal everyone recognises at once — and the workaround is the honest mitigation, funnier for being true.

## Run it

```sh
python3 main.py
```
